# Maintaining this portfolio

1. Only describe work you personally performed or clearly label it as a lab exercise.
2. Replace placeholders with verified details.
3. Add screenshots from your own environment.
4. Sanitize usernames, public IPs, MAC addresses, hostnames, domains, keys, tokens,
   passwords, and institutional or customer data.
5. Never commit `.env` files, private keys, VPN private keys, database passwords,
   backups containing personal data, or production configuration.
6. Record test method and observed result; do not write a test as successful until
   you have run it.
